# R-20.3 · 旋钮映射

**日期** 2026-11-06　**花费** ¥0

## 做了什么

六维 → 四旋钮（verbosity / initiative / warmth / recall_breadth）→
一行行为指令。**不写"我现在很生气"**，手册原话的红线。

## 输出格式

```
[状态] 愉悦80 愤怒30 → 语气轻快，检索广度大
[状态] 平静 → 一切照常
[状态] 愤怒85 紧张40 → 少主动发问，话少，检索广度大
```

只列**显著维度**（偏离基线 ≥15）；四旋钮全中性时报"一切照常"。
行硬约束 ≤60 字——逐短语装配、装不下丢次要的（温度 > 追问 >
话长 > 广度），断言兜底，**不截断**（截断会留半句鬼话）。

## 关键决定

- **基线相对偏移驱动，不是绝对值驱动**：基线 joy 70 的人常年 62
  不算低落，基线 55 的人 62 是真的愉快。阈值 ±15。
- **缺省值按基线算不按 0 算**：测试只传 `{"joy": 80}` 时其它维度
  是"没读到"不是"0"——按 0 算会让 surprise 0-20=-20 被误判显著，
  行里出现"好奇0"。实测抓到的 bug。
- **零旋钮不给短语**：knob=0 跳过，不选"中性偏档"。实测抓到的
  bug：全基线时凭空出现"语气偏冷"。
- **旋钮叠加语义**：joy+anger 的 verbosity 抵消（+0.5-0.5=0）→
  输出中性。矛盾情绪表达中性是合理解释，不算 bug（R-20-Gate 有记）。

## 手册映射表逐行实现

| 情绪 | 旋钮 |
|---|---|
| joy↑ | warmth+ verbosity+ |
| sadness↑ | verbosity− initiative−（warmth 不动：悲伤不是冷漠） |
| anger↑ | verbosity− recall_breadth+（"直接度"并入 warmth 侧语义） |
| fear↑ | initiative−（确认倾向并入"少自作主张"） |
| disgust↑ | warmth− |
| surprise↑ | initiative+（追问） |
