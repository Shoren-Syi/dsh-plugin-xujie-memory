# R-31 · 接手基线与本地内核加固（进行中）

日期：2026-11-06。工作副本：`C:\h\hippo`。

## 已发现并处理

- Windows 上 `os.kill(parent_pid, 0)` 会终止目标进程；改为等待父进程句柄。Unix 使用信号 0 检测。父进程消失后结束内核进程。
- 内核曾开放任意跨域访问。现在只接受回环 Host，浏览器请求如携带 Origin 则必须与内核地址同源。此措施防网页跨域及 DNS 重绑定，不构成本机进程之间的认证。
- 抽取密钥曾放在子进程参数并写入启动日志；插件启动改为经子进程环境传递。隔离实例已有日志中的历史启动参数已脱敏。
- 新启动内核带随机实例标识，宿主必须核对健康检查的标识，避免误认占用端口的其他服务。
- 日志文件句柄关闭后可以重新打开。
- 原流式测试依赖 TCP 分块数，无法可靠判断缓冲；改为让假上游在首个事件后暂停，验证首个事件在上游继续之前到达客户端。
