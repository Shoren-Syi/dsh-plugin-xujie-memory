## 凭据与安装

- 插件通过 DSH `credentials.resolve('DEEPSEEK_API_KEY')` 读取当前实例的 API key，不再直接解析固定位置的 DSH 凭据文件。优先级为插件配置、环境变量、DSH 凭据服务、海马体配置。自动抽取要求 API key；仅有账户登录不等于具有 API key。
- 同时修复并发启动时可能重复拉起内核的问题，及解释器启动失败时未处理子进程 error 的问题。
- DSH 独立实例中移除环境变量后，使用该实例的凭据服务成功启动带抽取配置的内核；不输出凭据值。
- 看板在未配置 API key 时显示“仅保存对话，暂不自动提取记忆”，连接失败时不再展示开发机测试路径。
