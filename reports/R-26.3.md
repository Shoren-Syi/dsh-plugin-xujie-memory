# R-26.3 · 基线对照（给外部看的那张表）

**日期** 2026-11-06　**花费** ¥0

## 一句话

> 用**全量重读 1/7.7 的成本**，拿到 **96% 的长程召回**；同样 576 token 的预算下，
> 全量重读只能装最近 5 轮对话，召回 6%。

## 三组对照

同一份 200 轮语料、同一批 50 条针、同一套评测。

| 组 | 做法 | 召回 | 矛盾率 | token/轮 | 成本 | 装配延迟 |
|---|---|---|---|---|---|---|
| **A · none** | 只带最近 5 轮 | 0.060 | — | 549 | 1.00x | 0.1ms |
| **B · full** | 全部历史，超 8000 截断 | **1.000** | 0.000 | 4412 | **8.04x** | 0.6ms |
| **C · hippo** | 本方案五段装配 | 0.960 | 0.000 | 576 | **1.05x** | 1.4ms |

分类明细（命中/总数）：

| 组 | 事实 | 关系 | 偏好 | 计划 | 伏笔 |
|---|---|---|---|---|---|
| A | 0/15 | 2/12 | 0/10 | 0/8 | 1/5 |
| B | 15/15 | 12/12 | 10/10 | 8/8 | 5/5 |
| C | 15/15 | 11/12 | 10/10 | 8/8 | 4/5 |

## 三个必须一起看的数

### 1. B 的召回是 1.000，比 C 还高——这不是 C 输了

全量重读把所有历史塞进 prompt，信息当然全在。**它的问题从来不是记不住，
是贵**：200 轮之后每轮 4.4k token。按每天 30 轮算，一年就是 4800 万 token。

C 要做的是在 1/8 的钱里买到 96%。剩下 4% 是两条：一条是中文"姓+职业"
的后缀匹配（`医生` vs `陈医生`，M10），一条是上位词（`动物` vs `狗`，M12）。

### 2. 同样的预算，B 只能装 5 轮

真正公平的对比不是"B 花 8 倍钱"，而是"给 B 同样 576 token"：

```
$ （full 截到 576 token，含人设 300）
C=576 token 能装最近 5 条 turn，召回 3/50 = 0.06
```

**576 token 里人设占 300，剩 276 装对话，只够 5 条 turn。**
而 C 在同一份预算里装了：15 条事实（角色卡）+ 8 条相关记忆 + 存疑/计划。

这就是"装配"和"堆历史"的区别：堆历史是 O(n) 的成本换 O(1) 的信息，
装配是 O(1) 的成本换 O(相关) 的信息。

### 3. A 的 0.06 不是"什么都没记住"

它答对了 3 条：P18（我妈高血压）、P47（老家绍兴）、P49（手术排期）——
这三条都在第 200 轮附近被提过。**"最近 5 轮"能记住的，恰好是刚说过的**，
这也解释了为什么很多人觉得"AI 记性还行"：他们只测了刚说过的事。

长程记忆的价值在第 8 轮说的过敏、第 46 轮说的学校。那些 A 一条都答不出。

## 成本怎么读

实测 200 轮的平均分布：

```
A  549 token = 人设 357 + 最近 5 轮 192
B 4412 token = 人设 357 + 全部 200 轮 4055
C  573 token = 人设 357 + 事实卡 136 + 记忆 66 + 动态 1 + 锚 11
                （memory 峰值 519，总峰值 1045，都远低于 1100 预算）
```

- 相对 A：**1.05x**（比手册示例的 1.15x 还低）
- 相对 B：**0.131**（DoD 要求 ≤0.15，M26.3 要求 ≤0.20）

这张分布说明两件事：

1. **人设是固定成本，占 62%**。所以"装记忆插件贵不贵"这个问题，
   答案取决于分母怎么算：相对整轮 5%，相对"纯记忆部分"（66 token）
   则是从 0 到 66。
2. **事实卡 136 token 是常驻的**（15 条当前状态），它替代了"每次重新
   从对话里找"。这 136 token 让 15/15 条事实不需要检索就能答——
   比把 15 条散落在 200 轮里便宜得多。

## 结论怎么写进 README

> 海马体把上下文从"最近 5 轮"扩到"整段关系的要点"，每轮多花 5% 的 token
> （相对不装插件），换来 16 倍的长程召回；相对全量重读省 87% 的成本，
> 召回只低 4 个点。

## 复现

```bash
for cfg in none full hippo; do
  python -m hippo.tools.eval_all --mode $cfg
done
```

数字完全可重复（两次独立跑逐字节一致），见 R-26.2 的"可重复性"一节。
