# R-7.3 inferred 前缀与注入过滤

> 里程碑：M7.3
> 日期：2026-11-05
> 数据：`tools/probe_inferred.py`（专项探针，¥0.0013）
> 结论：**形式达标，流量不足**。14 个窗口里 inferred = 0 条，前缀逻辑只有单测和一次专项探针支撑。

---

## 一、三条规则

```python
def format_trait(t):
    return f"（我的推测）{t.trait}" if t.status == "inferred" else t.trait
```

注入分三道闸：

| 闸 | 条件 | 挡掉什么 |
|---|---|---|
| `valid_to is None` | 已失效的不注入 | "他以前在字节"被当成现状 |
| `confidence >= 0.5` | 低置信度不注入 | 一条 0.45 的推测挤掉两条 0.9 的事实 |
| `max_n` | 调用方限条数 | 40 条特征吃掉 800 token，其中 30 条这个月没用上 |

排序规则：`observed` 在前，同状态按 `confidence` 降序，同分按 id。
这不是审美问题——**模型读上下文的注意力是有限的，前 3 行决定它记住谁**。

## 二、真实流量里 inferred 是 0

```
$ python3 -m tools.eval_m7
traits 总计 13（active 13，inferred 0 = 0%）
```

手册验收第 1 条是"inferred 必带前缀 100%"。0 条 inferred，
这个 100% 是 0/0，**分母为零的达标不算达标**。

所以我单独做了一个探针：五句话，每句都在暗示，没有一句直说。

```
今天又加班到十点，老板还在群里阴阳怪气
算了不说了，反正说了也没用
我最近老失眠，三点多就醒
有时候觉得这工作真没意思
不过年终奖还没发，先忍着
```

```
$ python3 -m tools.probe_inferred
traits 1 条，其中 inferred 1 条

  [inferred] （我的推测）工作经常加班到很晚，且对当前工作感到倦怠
             slot=employer conf=0.60 ev=[1, 4]
```

三件事同时被验证：

1. 模型**会**输出 inferred（不是永远 0）
2. `format_trait` 的前缀生效
3. `evidence` 挂在 `[1, 4]`，即"算了不说了"和"年终奖还没发"两条，
   而不是笼统挂全部 5 条 —— prompt 里新加的"指向真正说了这件事的那一条"
   起作用了

为什么 14 窗口里 0 条？因为 CORPUS 里大部分是日常叙事，
用户直接说事实，没有推断空间。**推断只在"话没说透"时发生**，
这是对的，不该为了指标去逼模型猜。

## 四、置信度阈值 0.5 是拍的

手册没说阈值，我定了 0.5。依据只有一条：`add_trait` 的初始值是 `confidence=0.6`，
重复一次到 0.7，两次 0.8。0.5 以下意味着"第一条证据都没攒够"。

这个数字**没有数据支撑**，属于"先定一个能跑的，等真实流量再说"。
M9 注入上线后应该看两件事来调：

- 被挡掉的 trait 里，有多少后来被用户确认了（漏注入）
- 注入的 trait 里，有多少被用户纠正了（错注入）

现在两个都测不了，因为没有用户反馈回路（M12 才有）。

## 五、和手册不一致的地方

| 项 | 手册 | 实现 | 理由 |
|---|---|---|---|
| 低置信度例外 | "除非被检索命中且有 doubt 需要澄清" | **未实现** | 需要 M10 检索 + M12 doubt 调度，现在没有调用方 |
| 注入条数 | 未限 | `render_traits(max_n=)` 参数留给调用方 | 不在这里拍上限，M9 按 token 预算决定 |
| CLI 展示 | 只列 active | **active + 已失效都列**，失效标 `(已失效)` | "他以前在哪工作"也要能查 |

## 六、这节没做到的

1. **没有真实用户看到过这张卡。** 可解释性是给人用的，
   现在只有 `hippo traits` 一个出口，没有任何地方把卡渲染进对话。
   那是 M9 的事，但也意味着这一节的价值目前只体现在"以后不会漏"。
2. **"低置信度 + doubt 澄清"的例外路径空着。** 代码里没有这条分支，
   只有注释。M12 接上之前，它是纸面设计。
3. **前缀只有一种写法。** 「（我的推测）」在中文里很突兀，
   可能让模型过度谨慎（把推测当不可说）。替代方案是用英文
   `[inferred]` 或者干脆在卡头写一段说明。没做对比实验。
