## 3. 现在这条链路长什么样

```
客户端 ──► 代理
            ├─ 识别 session
            ├─ 读最近 40 条 turns（常驻连接，0.05ms）
            ├─ 取本轮最后一条 user  ← 新增
            ├─ 转发上游（原样，只加 stream_options）
            ├─ 逐行透传 + 累积 assistant 文本  ← 新增
            └─ 收到 [DONE] 当场结账  ← 新增
                 ├─ turns：user + assistant
                 └─ metrics：四时间点 + usage + 成本

20 轮之后：
turns = 40 条，idx 0–39 连续，按 session 隔离
```

## 4. 偏差汇总

| # | 偏差 | 理由 |
|---|---|---|
| 1 | 只记「最后一条 user」 | 防客户端改写历史时污染全库 |
| 2 | 64k 字符上限 | 防爆库 |
| 3 | `_is_duplicate` 去重 | 防客户端重试重复记账 |
| 4 | 常驻写连接 | 4.5ms → 0.072ms |
| 5 | 切点只在 user 边界 | 半轮对话对抽取器无意义 |
| 6 | `settle` 在 `[DONE]` 当场执行 | 不等 `finally`，否则丢最后一轮 |
